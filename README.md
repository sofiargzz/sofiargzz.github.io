Descripción y propósito del proyecto
Este proyecto es un portafolio web personal diseñado para mostrar trabajos de diseño gráfico, ilustración y branding. El objetivo principal es proporcionar una plataforma limpia, minimalista y profesional donde los clientes potenciales puedan explorar servicios, proyectos anteriores y acceder a información de contacto de manera rápida.

Stack tecnológico utilizado
HTML5: Para la estructura semántica del contenido.

CSS3: Para el diseño visual, incluyendo el uso de Flexbox para la disposición de elementos, bordes redondeados y fondos con degradados.

GitHub Pages: Como plataforma de hosting y despliegue continuo.

Visual Studio Code: Como entorno de desarrollo principal.

Instrucciones de configuración para desarrollo local
Para realizar cambios en este proyecto de forma local, sigue estos pasos:

Clona el repositorio: git clone https://github.com/sofiargzz/sofiargzz.github.io.git.

Navega a la carpeta del proyecto: cd sofiargzz.github.io.

Abre el archivo index.html en tu navegador o utiliza la extensión Live Server de VS Code para ver los cambios en tiempo real.

Guía de personalización
Colores: Los colores principales se pueden modificar en el archivo CSS cambiando las propiedades de background-color en los contenedores.

Proyectos: Para añadir nuevos trabajos, debes duplicar el bloque de clase de proyecto en el archivo HTML y actualizar el texto y las imágenes correspondientes.

Fuentes: Puedes cambiar la tipografía importando nuevas fuentes desde Google Fonts en la cabecera del documento.
